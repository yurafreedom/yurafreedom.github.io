SITEBRAIN.
DOCUMENT INTELLIGENCE.

A source-linked document question-answering system for construction paperwork. A real application repository exists; public hosting and end-to-end testing are the next stage.

[ 01 / WHAT IT IS ]

Construction paperwork,
made searchable.

SiteBrain is an AI knowledge-base prototype for quotes, invoices, tender documents, schedules of rates and handwritten site dockets. It extracts structured details and answers questions with links to exact document pages and source passages.

[ 02 / PROCESS ]
01 / INGEST

Understand the document

Store originals, classify pages, process text and scans, preserve structural table rows and extract typed fields.

02 / INDEX

Keep evidence

Attach source page and positions to chunks, combine full-text search and vector retrieval, preserve provenance.

03 / ANSWER

Cite the source

Answers link to document excerpts and page coordinates; missing coordinate matches remain unlinked rather than fabricated.

[ 03 / PUBLIC DEMO ARCHITECTURE ]

Source code and a live demo are not the same thing.

GitHub Pages can serve a static showcase, but not this application’s Python backend, background processing or PostgreSQL. Cloudflare Pages alone is also not a drop-in host for the existing Docker Compose stack.

Visitor → FastAPI API → ingestion → PostgreSQL/pgvector
↳ Anthropic / OpenAI (server-side keys)
↳ source-linked answer + document viewer
  • Keep the public front-end and case documentation on GitHub Pages or Cloudflare Pages.
  • Deploy the existing API and worker logic in a Docker-compatible service, with a persistent database and file storage.
  • Preload fictional sample documents and restrict uploads and spending to avoid leaking user data or unexpectedly incurring API costs.
  • Verify HTTPS, CORS, migrations, rate limits and retention before sharing a public demo URL.
Launch gate: Do not publish the private repo or live inference keys before completing a security and licensing review. Live demo URL will be added only after deployment passes real tests.
